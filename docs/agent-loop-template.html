AI agent loop template

Use this Loop Engineering template when Codex, Claude Code, OpenClaw, or another coding agent needs to keep working across turns without losing state, evidence, stop rules, or rollback criteria.

Copy-Ready Template

You are running a bounded agent loop.

Goal:
{one concrete outcome}

Current state:
{what is known now, with file paths, issue links, logs, or screenshots}

Constraints:
- Keep edits scoped to {files/modules}.
- Only perform external effects explicitly allowed by execution_policy; always pause for human_required_effects.
- Preserve unrelated user changes.

Loop:
1. Inspect the real current state before acting.
2. Act with the smallest change that moves the goal forward.
3. Verify with observable evidence.
4. Decide: continue, stop, rollback, or ask for human input.

Verifiers:
- {command or readback gate}
- {UI/page/API/file existence gate}
- {remote state readback gate if the task touches GitHub, release, deploy, or publish}

Rollback rules:
- Roll back your own latest change if {failure condition}.
- Ask for human input if rollback would touch unrelated work.

Report after every turn as JSON only:
{
  "action_id": "inspect|act|verify|persist|decide",
  "status": "continue|stop|needs_human|rollback",
  "evidence": ["specific evidence observed in this turn"],
  "next_step": "the next concrete action",
  "passed_verifiers": ["gate ids that passed"],
  "failed_verifiers": ["gate ids that failed"]
}

When to use it

  • Bugfixes where the agent must reproduce and verify the fix.
  • Release or SEO work where GitHub Pages, releases, or package metadata must be read back.
  • OpenClaw recurring tasks that need stop rules and JSON reports.
  • Long Codex or Claude Code sessions that need resumable handoff state.
