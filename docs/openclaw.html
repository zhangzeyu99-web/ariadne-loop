Ariadne Loop for OpenClaw

Turn recurring OpenClaw work into loop-gated agent operations with verifiers, stop rules, rollback guidance, and JSON reports.

Build a packet Install CLI

Why it helps

Evidence first

OpenClaw reports what it inspected and which verifier passed before it continues.

Bounded autonomy

Stop rules and human gates keep publishing, sending, deleting, and external actions controlled.

Reviewable history

JSON reports make scheduled runs searchable and easier to debug after failures.

Setup

Install the skill or generate a packet, then paste it into OpenClaw as the task contract.

mkdir -p ~/.openclaw/skills/ariadne-loop
curl -L https://raw.githubusercontent.com/zhangzeyu99-web/ariadne-loop/main/skills/ariadne-loop/SKILL.md \
  -o ~/.openclaw/skills/ariadne-loop/SKILL.md

python -m pip install git+https://github.com/zhangzeyu99-web/ariadne-loop.git
ariadne-loop quickstart --output openclaw-loop-demo
# give openclaw-loop-demo/agent-packet.md to OpenClaw

The packet follows inspect -> act -> verify -> decide, then returns a JSON-only status report.

Good fits

  • Daily repo health checks and stale PR follow-up
  • Local service monitoring with readback after fixes
  • Documentation refreshes that must verify links and examples
  • Scheduled bug triage that should stop after repeated verifier failures
